# 🚀 Quick Tutorial

여기서는 **MDMan**을 백분 활용할 수 있는 간단한 팁들을 안내해 드립니다!

## 💡 유용한 팁

### 1. 단축키 바인딩
- **`Ctrl + S`**: 현재 편집 중인 파일을 즉시 로컬 파일 시스템에 저장합니다.
- **`Alt + 1`**: 왼쪽 파일 트리 사이드바를 접거나 펼쳐 화면 공간을 확보합니다.
- **`Alt + 2`**: 오른쪽 작업 히스토리 사이드바를 접거나 펼쳐 미니멀 모드로 전환합니다.
- **`Ctrl + Shift + F`**: 실시간 전체 텍스트 검색 창을 빠르게 엽니다.

### 2. 폴더 변경
- 최상단 헤더의 로컬 경로 옆 **[폴더 변경]** 버튼을 통해 사용자의 PC 내부의 어떤 폴더로든 전환할 수 있습니다.
- 존재하지 않는 경로를 입력하면 유효한 경로를 입력하거나 취소할 때까지 경고를 보냅니다.

### 3. 태그 탐색
- 문서 상단의 `tags` 항목에 태그를 작성해 두면, 시스템이 이를 스캔하여 태그 탐색기에 분류하고, 태그 클릭 시 해당 태그가 포함된 파일만 탐색기에 필터링해 줍니다!
