# 📝 Welcome to MDMan!

안녕하세요! **MDMan**은 로컬 폴더 내의 마크다운 파일들을 아름답고 컴팩트하게 관리할 수 있는 **프리미엄 마크다운 관리 도구**입니다.

## ✨ 핵심 기능 안내

1. **Obsidian 스타일 라이브 프리뷰**
   - 아래 서식을 입력하는 즉시 화면에 스타일이 실시간 반영됩니다.
   - `**굵은 텍스트**` -> **굵은 텍스트**
   - `*기울임 텍스트*` -> *기울임 텍스트*
   
2. **트리 뷰 드래그 앤 드롭 (Drag & Drop)**
   - 왼쪽 파일 트리에서 이 파일을 마우스로 끌어(Drag) 다른 폴더 위로 가져가면 네온 컬러로 반짝입니다. 놓으면(Drop) 로컬 파일 시스템에서 물리적으로 이동합니다!

3. **고속 전체 텍스트 검색**
   - `Ctrl + Shift + F` 또는 상단 검색 버튼을 통해 모든 파일의 제목 및 내부 내용까지 초고속으로 실시간 검색할 수 있습니다.

4. **안전한 휴지통 삭제**
   - 파일을 삭제할 경우 영구 파괴되지 않고, OS의 **실제 휴지통(Recycle Bin)**으로 이동하므로 안심하고 지울 수 있습니다.

5. **작업 관리 로그 (Activity Log)**
   - 폴더 변경, 이동, 삭제 등의 모든 활동이 오른쪽 히스토리 타임라인에 실시간 누적 기록됩니다.

오른쪽 패널에서 활동 내역을 확인해 보시고, 자유롭게 새 폴더를 만들거나 드래그해 보며 테스트해 보세요!
