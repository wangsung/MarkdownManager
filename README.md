# 📝 MDMan - Premium Markdown Folder Manager

분할 화면(Split-Screen) 환경에 완벽히 최적화된 **초밀착·고밀도 디자인**의 프리미엄 로컬 웹 서버 기반 마크다운 폴더 관리자입니다. 

에버노트(Evernote)의 강력한 3단 스플릿 레이아웃과 옵시디언(Obsidian) 스타일의 실시간 라이브 프리뷰(WYSIWYG) 편집기의 장점만을 결합하여, 로컬 마크다운 파일들을 직관적이고 아름답게 정리하고 편집할 수 있습니다.

---

## ✨ 주요 기능 (Key Features)

### 📂 1. 데스크톱급 3단 분할 레이아웃 (3-Column Layout)
- **1단 (왼쪽): 폴더 탐색기** - 마크다운 파일들을 배제하고 오직 계층 디렉토리 구조만 표현하여 복잡함을 걷어내고 폴더의 생성, 이름 변경, 안전 삭제를 처리합니다.
- **2단 (가운데): 파일 목록** - 활성화된 폴더 내의 `.md` 파일들만을 평탄화해 보여 주며, 다중 선택 상태를 네온 하이라이팅으로 명확히 인지시켜 줍니다.
- **3단 (오른쪽): 실시간 편집기/뷰어** - 강력한 TipTap 에디터 기반으로 GFM(GitHub Flavored Markdown) 서식을 편집 및 실시간 프리뷰할 수 있으며, 본문(Canvas) 내의 잡다한 노출 요소를 모두 제거하고 상단 프레임(Frame) 영역에 파일명과 생성/수정일이 단 1줄에 촘촘하게 표기됩니다.
- **활동 타임라인 (우측)** - 서버 변경 로그를 실시간으로 기록하며, 평소에는 접혀 있어 불필요한 공간을 차지하지 않습니다.

### 🖱️ 2. 다중 선택 및 배치 드래그 앤 드롭 (Multi-Drag & Drop)
- 데스크톱 탐색기 수준의 파일 다중 선택 기능 지원:
  * `Ctrl + 클릭`: 개별 파일 복수 선택 (Toggle)
  * `Shift + 클릭`: 클릭 시점부터 범위 내 파일 일괄 선택 (Range Select)
  * `체크박스 제어`: 마우스 호버 시 노출되는 미니 체크박스로 직관적인 복수 선택 지원
- 선택된 복수 개의 파일들을 통째로 잡고 1단 폴더 트리로 끌어다 놓으면(Drag & Drop), 백엔드가 병렬로 동시에 안전하게 이동시켜 주며 실시간으로 네온 피드백과 변경 내역이 동기화됩니다.

### 🔍 3. 초고속 전체 텍스트 검색 및 단축키 시스템
- `Ctrl + Shift + F` 또는 상단 검색 아이콘을 눌러, 폴더 전체 마크다운 파일들의 제목뿐 아니라 **본문 텍스트 내용**까지 실시간으로 하이라이트 매칭하여 초고속으로 인덱싱하고 클릭 즉시 파일로 열어 줍니다.
- `Ctrl + S` (마크다운 즉시 저장)
- `Alt + 1` (1단 폴더 트리 토글 접기/열기)
- `Alt + 2` (2단 파일 리스트 토글 접기/열기)
- `Alt + 3` (우측 숨겨진 작업 히스토리 타임라인 토글)

### 🛡️ 4. 안전한 OS 휴지통 삭제 및 무충돌 독점 설계
- 앱 안에서 파일/폴더를 지우더라도 즉시 영구 소멸하지 않고, **OS의 실제 시스템 휴지통(Recycle Bin)**으로 안전하게 보내주어 실수로 인한 파일 손실을 완벽히 방지합니다.
- 고유한 네임스페이스 설계(`mdman_server.py`)로 타 로컬 웹 서버 프로젝트 구동 시 발생할 수 있는 파일명 및 포트 충돌 걱정이 전혀 없습니다.

### 🖼️ 5. 이미지 로컬 업로드 및 클릭 가능한 링크 지원
- 편집창 안에서 스크린샷 이미지 붙여넣기(Paste) 또는 끌어다 놓기(Drop) 작동 시, 사용자 로컬 작업 폴더 내의 `assets/` 디렉토리로 안전하게 자동 업로드 및 마크다운 자동 기입이 완료됩니다.
- `[Edit]` / `[Preview]` 토글 스위치 제공 및 읽기 전용 모드에서도 외부 하이퍼링크가 정상적으로 클릭 가능하게 복구되어 새 브라우저 창(`_blank`)으로 부드럽게 열립니다.

## 🛠️ 기술 스택 (Technology Stack)

### Frontend
- **React 18** & **Vite 5** (HMR 지원 초고속 번들러)
- **TipTap Core & Starter-kit** (WYSIWYG 뼈대 엔진)
- **tiptap-markdown** (실시간 마크다운 동적 인코딩/디코딩 파서)
- **Lucide React** (네온 컬러 글래스모피즘 아이콘 시스템)
- **Vanilla CSS3** (에버노트 전용 프리뷰 테마 이식 및 초밀착 CSS 변수 디자인 시스템 설계)

### Backend
- **Python 3.10+**
- **FastAPI** & **Uvicorn** (고성능 로컬 API 엔지니어링)
- **Send2Trash** (OS 휴지통 안전 연동 모듈)
- **python-multipart** (로컬 미디어 파일 스트리밍)

## 🚀 시작하기 (Quick Start)

### 1. 백엔드 가상환경 설정 및 의존성 설치
```bash
# 의존성 설치
pip install -r requirements.txt
```

### 2. 프론트엔드 의존성 패키지 설치
```bash
# node 패키지 다운로드
npm install
```

### 3. 프로덕션 배포 빌드 컴파일
```bash
# Vite 빌드 수행
npm run build
```

### 4. 서버 원클릭 가동 (Windows 전용)
로컬 폴더 내의 **`run_mdman.bat`** 파일을 마우스로 더블 클릭합니다. 
자동으로 로컬 API 서버가 가동되며 웹 브라우저가 실행되어 **[http://127.0.0.1:8000](http://127.0.0.1:8000)**으로 바로 부드럽게 진입합니다!
